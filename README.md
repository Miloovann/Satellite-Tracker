# Satellite-Tracker
Tracking Singapore's satellites' orbits on a GUI//

By scraping the realtime [Two Line ELement][https://en.wikipedia.org/wiki/Two-line_element_set] realtime of satellites, we calculate their flight trajectories and orbital passes to determine whether a passing is ideal for communication with the satellite.

This data would be presented in a GUI developed using PyQt6 for researchers to monitor 🛰️ satellites 📡 and prepare beforehand for communications during an ideal orbital pass.
